PUBLICAR EN GITHUB PAGES
1. Extrae el contenido de esta carpeta.
2. Sube index.html, styles.css, app.js, data.js y .nojekyll a la raíz del repositorio.
3. En GitHub abre Settings > Pages.
4. Selecciona Deploy from a branch.
5. Selecciona main y la carpeta /(root).
6. Guarda y espera a que GitHub publique la liga.

ARCHIVOS
- index.html: estructura de la aplicación.
- styles.css: diseño responsivo, fondo oscuro, sombras, tarjetas y animaciones.
- app.js: filtros, cálculos, gráficos y acceso.
- data.js: datos extraídos de Venta SubTotal.
- .nojekyll: evita procesamiento innecesario de GitHub Pages.

NOTA DE SEGURIDAD
La validación de usuario y contraseña es del lado del navegador. Sirve como barrera visual,
pero no sustituye autenticación de servidor. Para acceso realmente restringido debe integrarse
Supabase Auth, Vercel Authentication o un backend.
