PUBLICACIÓN EN GITHUB PAGES
1. Sustituye en la raíz del repositorio los archivos index.html, styles.css, app.js y data.js.
2. Conserva .nojekyll.
3. Haz commit y espera la actualización de GitHub Pages.
4. Si el navegador mantiene la versión anterior, recarga sin caché o abre en modo incógnito.

SEGURIDAD
Las credenciales se validan en el navegador. En GitHub Pages son una barrera visual, no autenticación segura de servidor.
Para control real de acceso se recomienda Supabase Auth, Vercel Authentication o un backend.
